# GitHub

GitHub CLI (gh) is available.

For every completed project:

1. Initialize git

2. Commit

3. Create repository using GitHub CLI as private during development

gh repo create <repository-name> \
--private \
--source=. \
--remote=origin \
--push

After the project is finalized and reviewed, publish it publicly:

- change the repository visibility to public
- generate screenshots
- update README
- push again
