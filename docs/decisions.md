# Decisions

## Why Next.js

Next.js gives the repo a credible production baseline and keeps the path open for adding API routes, auth, or data fetching later.

## Why server-rendered first

The dashboard is mostly informational. Server rendering keeps it simple and fast for a portfolio demo.

## Why plain CSS

The first project is intentionally lightweight. Plain CSS keeps the setup focused and avoids introducing a utility framework before it is needed.

## Why mock data

This repository is meant for public distribution. Mock data avoids exposing internal business logic while still looking realistic.
